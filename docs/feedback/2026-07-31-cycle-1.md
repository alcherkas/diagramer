## UX issues

1. **Empty canvas is a dead end**: a first-time user sees a dotted canvas with
   zoom controls and no hint of what to do. REQ-001 (palette) is confirmed as
   the top priority; its palette should be visible by default (not behind a
   toggle) so the first-run experience explains itself.
2. **Dark theme mismatch**: app chrome background is `#111827` while the React
   Flow canvas dark background is `#141414` — visible seam at the header
   border. Noted in REQ-009.

## Opportunities

1. **No way to reach Container/Component diagrams**: documents default to the
   `context` kind and nothing in the backlog lets the user switch kinds, so
   Container/Component/Boundary elements (REQ-001) would be unreachable in the
   UI. Filed REQ-011 (diagram kind switcher, P2, ready) — should land right
   after REQ-001/002.
