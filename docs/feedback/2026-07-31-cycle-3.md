## Bugs

1. **Edge labels can be occluded by nodes** (REQ-012, P1). When the bezier
   midpoint falls under a node (easy to produce when the target sits
   down-right of the source), the label renders *underneath* the node card and
   cannot be clicked or double-clicked — the node intercepts pointer events.
   Editing/deleting that relationship via its label becomes impossible.
   React Flow renders the edge-label layer below the nodes layer by default;
   the label layer needs to stack above unselected nodes.
