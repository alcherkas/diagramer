## UX issues

1. **Dragging from a node's edge moves the node instead of starting a
   connection** — users will expect an edge gesture. When REQ-002 lands,
   consider a generous `connectionRadius` and allowing a connection drop on
   the node body (snap to nearest handle), not only on the 8px handle dot.
2. **Relationships are the top gap**: handle-drag currently produces nothing
   (no default edge type registered). REQ-002 remains the highest-value next
   step; its notes updated with the snap-to-body guidance.
3. Error toast (`ui.lastError`) never auto-dismisses once shown. Minor;
   folded into REQ-003 notes (inspector/UX polish will touch this area).
