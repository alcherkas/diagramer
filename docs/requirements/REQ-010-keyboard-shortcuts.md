# REQ-010: Keyboard shortcuts

- **Status**: ready
- **Priority**: P3
- **Source**: vision
- **Created**: 2026-07-31
- **Updated**: 2026-07-31

## User story

As a power user, I want keyboard shortcuts for common actions so that editing
is fast.

## Acceptance criteria

- [ ] Delete/Backspace removes selection (exists); Cmd/Ctrl+A select all;
      Cmd/Ctrl+D duplicate (+20px offset); Cmd/Ctrl+C/V copy/paste with new
      ids; F fits view.
- [ ] Undo/redo shortcuts per REQ-005.
- [ ] All shortcuts suppressed while typing in inputs.
- [ ] A "?" shortcut (or toolbar item) shows a shortcut reference overlay.
- [ ] e2e: duplicate and copy/paste round-trip via keyboard only.
